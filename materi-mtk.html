ANGGOTA 01

Model Matematika Kevin

Lihat Materi

Variabel

x = Harga satu buah Reglow Tree
y = Harga satu buah EcoLotus Lamp

Persamaan

2x + 3y = 265.000
x + 4y = 245.000

Metode Campuran

1. Eliminasi
2x + 3y = 265.000 | ×4
x + 4y = 245.000 | ×3
8x + 12y = 1.060.000
3x + 12y = 735.000
5x = 325.000
x = 325.000 : 5
x = 65.000
2. Substitusi
x + 4y = 245.000
65.000 + 4y = 245.000
4y = 245.000 - 65.000
4y = 180.000
y = 180.000 : 4
y = 45.000
Kesimpulan

Jadi, harga satu buah Reglow Tree adalah Rp65.000 dan harga satu buah EcoLotus Lamp adalah Rp45.000.

ANGGOTA 02

Model Matematika Keysa

Lihat Materi

Variabel

x = Harga satu pot dari keyboard
y = Harga satu ecoclock

Persamaan

2x + 3y = 100.000
3x + 2y = 120.000

Metode Campuran

1. Eliminasi
2x + 3y = 100.000 | ×2
3x + 2y = 120.000 | ×3
4x + 6y = 200.000
9x + 6y = 360.000
-5x = -160.000
5x = 160.000
x = 32.000
2. Substitusi
2x + 3y = 100.000
2(32.000) + 3y = 100.000
64.000 + 3y = 100.000
3y = 100.000 - 64.000
3y = 36.000 : 3
y = 12.000
Kesimpulan

Jadi, harga satu pot dari keyboard adalah Rp32.000 dan harga satu EcoClock adalah Rp12.000.
